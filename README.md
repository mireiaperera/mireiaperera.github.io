# Putting this online for free (GitHub Pages)

All files are in ONE flat folder on purpose — upload them all together.

1. github.com → New repository → name it `YOURUSERNAME.github.io` → Public → Create.
2. Click "uploading an existing file", drag in every file from this folder, Commit.
3. After 1–2 minutes the site is live at https://YOURUSERNAME.github.io

## Contact form (one-time setup, free)
The form sends to Formspree so your email is never on the page.
1. Go to formspree.io → Sign up (free: 50 messages/month).
2. New form → give it a name → copy the form ID (looks like `xabcdefg`).
3. In index.html, search for `FORMSPREE_ID` and replace it with that ID. Commit.
4. Send yourself a test message from the site; the first one asks you to confirm your email.
